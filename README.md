Stone Paper Scissors

A simple command-line Stone Paper Scissors game built using Python. The player plays against the computer, which randomly selects its choice in every round.

How the Game Works:
The game follows the usual Stone-Paper-Scissors rules:
•	Stone beats Scissors
•	Scissors beats Paper
•	Paper beats Stone
•	If both choices are the same, the round is a draw

The computer randomly chooses one of the three options, and the result of the round is displayed along with the current score.
The game continues until the player chooses to exit.

Features:
•	Computer makes a random choice every round
•	Keeps track of both user and computer scores
•	Allows multiple rounds in a single execution
•	Displays the score after every round
•	Provides an option to exit the game
•	Handles invalid choices with a simple error message

Tech Stack Used:
•	Python 

How to Play:
After starting the program, you will see the available choices:

stone
paper
scissors
Exit
Enter your choice exactly as shown.

For example:
Enter your choice: stone
The computer will then randomly select its choice and the program will announce the winner.
Example:
The user's choice is stone and computer choice is scissors
The winner is USER

THE SCORES:
USER- 1
COMPUTER- 0
Exiting the Game
To exit, enter:Exit
Exit
Note: The current version is case-sensitive. Use stone, paper, scissors, or Exit exactly as shown.
